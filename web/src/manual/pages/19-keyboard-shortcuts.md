# Keyboard shortcuts

Press `?` anywhere (outside a text field), or click **Keyboard shortcuts** at the top of this manual, for the shortcut overlay. `F1` opens the help of the selected block, or this manual when no block is selected.

Single-key shortcuts (`R`, `F`, `N`, `?`, `/`) do not fire while you type in a field.
