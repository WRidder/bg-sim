# pendulum-double-fixed — a double pendulum on a fixed pivot: swing-up, catch, balance, recovery

A planar double pendulum hangs from a fixed pivot (plan 9.x, X5.11). A DC gearmotor drives the first joint only (pendubot type), the other 1 joint is passive. The chain starts hanging at rest with 0 V on the motor. At t = 1 s it swings up along a **trajectory-optimised** feed-forward tracked by a **time-varying LQR**, is caught near the upright by an infinite-horizon **LQR** (1 kHz, `@discrete`), balances, and 3.7 s after the catch a 50 ms force pulse of 0.4 N at the tip link is recovered.

```
Clock ─ t ───────────────────────────────┐
Joint1..2 ─ q, qdot ───────────────────────┼─► Ctrl (double swing-up / catch / balance, 1 kHz, ±12 V) ─ u ─► Motor ─ Shaft ─ Gear ─► Joint1
                                           └─ phase
Ground ─ Joint1 ─ Link1 ─ BodyJ1(Body1) ─ Joint2 ─ Link2 ─ BodyJ2(Body2) ◄─ Hit (tip force pulse)
```

## Plant (multibond bond graph)

| part | block |
| --- | --- |
| links | `stdlib:planar/RigidBody2D`, a rod with distributed mass: COM at the middle, $J = mL^2/12$ |
| joints | `stdlib:planar/Revolute2DCompliant` (`kt` = 1e8 N/m converges to the rigid revolute; the rigid variant is index 3), viscous friction `b`; joint 1 carries the motor, the others a zero `Se` |
| gravity | inside `RigidBody2D` (`GravityPlanar` on the composed pose) |
| drive | `stdlib:drives/ElectricDrive` → `stdlib:rotation/ElasticShaft` → `stdlib:drives/Gearbox` → joint 1; the shaft keeps the rotor inertia integral-causal (no W201) |
| disturbance | `stdlib:multibond/ExternalWrenchPlanar` on the last link's 1-junction, three `Pulse`/`Constant` sources (force and the torque of the tip lever arm) |
| controller | project block `DoublePendCtrl` (`library/DoublePendCtrl.jl`, generated by `design/design.py`) |

Parameters (assumed, no datasheet part):

| link | m [kg] | L [m] | COM [m] | J [kg m²] | b [N m s/rad] |
| --- | --- | --- | --- | --- | --- |
| 1 | 0.22 | 0.3 | 0.15 | 0.00165 | 0.002 |
| 2 | 0.14 | 0.36 | 0.18 | 0.001512 | 0.0008 |

Motor: R = 2.5 Ω, L = 0.5 mH, k_t = 0.03 N m/A, rotor J_m = 5e-06 kg m²; gear ratio N = 5 (reflected rotor inertia 0.000125 kg m²); shaft k = 5000 N m/rad, d = 0.2 N m s/rad on the motor side; supply limit ±12 V (stall torque at the joint 0.72 N m).

Angles: `q1` is the absolute angle of link 1 from +x (hanging −π/2, upright +π/2), the other joint angles are relative. The model has an inline block `Upright` with the absolute link angles from upright, `Upright/a1..a2`, used for plots and checks.

Every bond points from the port into the junction. A reversed bond flips the junction's sign convention, and the plant stops matching its equations (found the hard way while building this example).

## Design (`design/`)

| file | what |
| --- | --- |
| `params.py` | plant, scenario, weights |
| `design.py` | the whole flow: CasADi dynamics, direct collocation (Hermite–Simpson, IPOPT), TVLQR, LQR, the catch rule, a sampled-data prediction of the run, writes `library/DoublePendCtrl.jl`, `expected.json`, `results.json` |
| `build_model.py` | `models/*.bgmodel.json` and `scenes/*.sdf` |
| `build_docs.py` | the source of the model docs (`tools/example_docs`) |
| `pendulum_*.py` | shared code (the triple imports it from `pendulum-double-fixed/design`) |

```
uv run examples/pendulum-double-fixed/design/build_model.py
uv run examples/pendulum-double-fixed/design/design.py
uv run examples/pendulum-double-fixed/design/design.py --compare run.npz     # model `free` run vs the design ODE
```

Trajectory: 100 Hermite–Simpson intervals over T_s = 2.5 s, |u| ≤ 11 V, cost ∫(u/u_lim)² dt. TVLQR and LQR weights Q = diag(100, 100, 1, 1), R = 1. Catch rule: V(x) = (x−x_up)ᵀ P (x−x_up) < 3.3. LQR K = -99.69, -93.59, -24.43, -13.59.

## Measured

| quantity | value |
| --- | --- |
| design model vs bond graph, free swing (3 s, max over joints) | 2.91e-06 rad |
| swing-up | starts 1 s, trajectory time 2.5 s |
| catch (phase 2) | 3.301 s |

| disturbance | 0.4 N, 50 ms at 7 s |
| peak deflection after it | link 1: 16.63 deg, link 2: 8.71 deg |
| recovery (all links inside 1 deg) | 8.045 s, 1.04 s after the pulse starts |

| compile + run (real worker) | 28 s (of which the run 20 s), 26305 output rows |

The prediction of `design.py` (CVODES on the non-linear model with the winding current, the same tables) agrees with the bond-graph run to 1.8e-05 rad in every link angle.

## Checks

`uv run examples/run_checks.py --only pendulum-double-fixed` runs `expected.json`: hanging at rest before t_on, the phases and the catch time, upright by t_on + T_s within 0.2 deg until the disturbance, the disturbance peaks (5 %), recovery, the voltage within the supply, the free swing against the design ODE, the 3D forward kinematics from the joint bindings against the composed poses, no diagnostics. The docs of the model (`models/pendulum-double-fixed.docs`) are linted by the same command. Browser acceptance: `web/tests/e2e/pendulum-fixed.spec.ts` (real worker).
