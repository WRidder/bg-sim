You own `web/src/inspector/` and may add tests. Read the store API and use its commands; do

### 2. Deliverables (plan 7.2, 7.4)
- The inspector panel for the selected node:
  - name (rename with uniqueness checks against siblings, live validation);
  - block ref and its description, with "Open source" and "Copy to project library";
  - **parameters** as expression strings (plan 3.3 `params`), each showing its unit, min/max
    and description from the catalog, with inline validation (min/max bounds, unit
    dimensional check is server-side — show the diagnostic when it arrives);
  - **constants** (structural, integer/text/number by declared type, with the `structural`
    note of D13);
  - **starts** (start-value overrides per variable, with the declared unit);
  - ports list with domain letters and a read-only signal-id display.
- Multiple selection shows a compact summary; no selection shows a guidance empty state.
- Every edit goes through the store so undo/redo works (plan 7.4: "edit R, then undo it").

### 3. Tests

- Playwright (`tests/e2e/inspector.spec.ts`, fake worker): select a node, change `R`, see the
