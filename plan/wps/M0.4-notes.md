## Orchestrator notes

### 1. Extend, do not recreate, the backend harness from M0.2
`backend/` already exists: a uv project named `bgsim-server`, `.python-version` pinned to 3.13,
`src/bgsim_server/{__init__.py,contracts.py}` (generated pydantic v2 models) and
`tests/test_contracts.py`, with `pytest`, `pytest-asyncio`, `httpx`, `ruff`,
`datamodel-code-generator`, `jsonschema` and `pydantic` already added. Add per plan section 6:
`uv add fastapi 'uvicorn[standard]' numpy watchfiles`. Do not remove the contracts test.

### 2. Files and responsibilities (plan section 6 and 2.2)
- `backend/src/bgsim_server/config.py` — settings: host `127.0.0.1`, port `8765` (env
  `BGSIM_PORT_HTTP` optional), `projects_root` (env `BGSIM_PROJECTS_ROOT`, default
  `~/bgsim-projects`), julia executable from `BGSIM_JULIA` or `julia` on PATH, repo root
  discovery, `BGSIM_FAKE_WORKER` flag, worker log path `backend/logs/worker.log`.
- `backend/src/bgsim_server/app.py` — FastAPI application factory; `GET /api/health`
  returning `{ "backend": "<version>", "worker": "starting"|"warming"|"ready"|"crashed",
  "versions": {...} }` exactly as plan 3.7; serves `web/dist` at `/` when it exists
  (static files + SPA fallback) and returns a small JSON at `/` when it does not; lifespan
  hook starts and stops the worker supervisor.
- `backend/src/bgsim_server/__main__.py` — `main()` runs uvicorn on 127.0.0.1:8765.
  `[project.scripts] bgsim = "bgsim_server.__main__:main"` so `uv run bgsim` works.
- `backend/src/bgsim_server/worker.py` — the supervisor:
  - listens on a random free localhost TCP port, then spawns
    `julia --project=<repo>/julia/BGSim --threads=2 -e "using BGSim; BGSim.Worker.main()"`
    with `BGSIM_PORT=<port>` in the environment (absolute path from `BGSIM_JULIA` or PATH —
    on this machine `shutil.which("julia")` finds the juliaup shim; use it);
  - framing exactly as plan 3.6: `u32 LE length`, `u8 kind` (0 JSON, 1 binary), payload;
  - request/response correlation by `id`, concurrent requests allowed, per-method timeouts
    (`block.check` 5 s, `model.check` 60 s, runs unlimited), a notification fan-out with one
    `asyncio.Queue` per run;
  - stdout/stderr of Julia captured to `backend/logs/worker.log` and never treated as protocol;
  - a health state machine (`starting` → `warming` → `ready`, `crashed`) and auto-restart with
    backoff; expose `worker_restarted` as a notification;
  - `BGSIM_FAKE_WORKER=1` replaces the subprocess with an in-process fake that answers
    `ping`, `catalog.get` (from `contracts/fixtures/catalog/valid/catalog.min.json`),
    `model.check` (from `contracts/fixtures/diagnostic/valid/diagnostics.sample.json`),
    `run.start`/`run.cancel` (writing a synthetic `columns.f64` with real timing, sines and
    steps, per plan 6) and `cache.clear`. The fake must make `/api/health` reach `ready`
    within about a second, and it must speak the same framing over a real socket, not just
    return objects, so that M0.5's e2e and P1.x's tests exercise the same path.
- `backend/tests/` — pytest: health endpoint (fake), framing round-trip (fake), a
  request/response correlation test with two in-flight requests, a notification test, and a
  restart/backoff test if it can be made deterministic. Mark the real-worker test
  `@pytest.mark.julia` and skip it by default (`pytest.ini`/`pyproject` markers and
  `addopts = -m "not julia"`).

### 3. The Julia worker stub — the only file you may touch under `julia/`
`julia/BGSim/` exists (M0.3) with `Project.toml` (ModelingToolkit, JSON3, Sockets, ...) and
`src/BGSim.jl`. Create `julia/BGSim/src/worker/protocol.jl` and
`julia/BGSim/src/worker/server.jl` defining `module Worker` with `main()` that:
- reads `BGSIM_PORT`, connects to `127.0.0.1:<port>`, and serves frames;
- answers `ping` with `{"version": <BGSim version>, "julia": string(VERSION), "warm": true}`;
- answers unknown methods with a proper `{ "id": n, "error": { "message", "diagnostics": [] } }`;
- logs to stderr only;
- handles binary frames without crashing (reject them cleanly).
You may add **exactly one** `include("worker/server.jl")` line to `src/BGSim.jl` (plus, if
needed, `using Sockets, JSON3` in that file). Do not change anything else under `julia/BGSim/`.
M0.3's `julia/BGSim/NOTES.md` is authoritative for MTK APIs; you do not need MTK here.

`worker: "ready"`. Record the real-worker `ping` round-trip time and the cold worker start
time to `ready` (this is the section 5.12 "worker cold start" measurement: record it in your
report, the orchestrator puts it in STATUS).
