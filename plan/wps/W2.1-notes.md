## Orchestrator notes

### 1. What exists
W1.1 built the canvas, the document store, `web/src/editor/DiagramTab.tsx` (the canvas host) and
`web/src/editor/ModelTree.tsx`. W1.2's inspector emits a DOM event `bgsim:open-source` with
`{kind, ref, line, col}` when "Open source" is clicked, and W1.3's diagnostics panel emits the
same event for a source-level diagnostic. `web/src/code/CodeTab.tsx` already exists (a
placeholder) and is mounted in the centre tab area by `CenterTabs`, so **you do not need to edit
the app shell**.
The backend proxy `POST /api/check/block` with `{"source", "ref"}` returns
`{diagnostics, interface}` (P1.3); the fake worker answers it from the catalog fixture, so you
can develop the editor without Julia. Read `backend/src/bgsim_server/proxy.py` and
`contracts/schemas/worker-rpc.schema.json`.

### 2. What to build (plan 7.7, 7.4)
1. CodeMirror 6 (`@codemirror/view|state|language|lint|autocomplete|legacy-modes` are installed)
   with the Julia legacy mode plus a small highlighter for the scope macros
   (`@block @constants @parameters @inputs @outputs @ports @variables @initial @equations
   @discrete @events @components @connections @causality`) and the `~` operator.
2. Lint: debounce 300 ms, call `check/block`, map each diagnostic to `@codemirror/lint` with its
   code, message, hint and range (line/col/endLine/endCol are 1-based in the contract; convert
   to CM offsets carefully and write a test for a multi-line range).
3. Autocomplete: the whitelisted functions (the parser's whitelist), the names declared in the
   current block, the port fields (`p.e`, `p.f`) for each declared port, and unit strings inside
   `unit = "..."`.
4. Read-only mode for stdlib sources with a "Copy to project library" banner (the copy action
   already exists in `web/src/inspector/copyToLibrary.ts` — reuse it, do not duplicate).
5. **Inline equation and discrete code nodes**: a node whose `block` is
   `{inline: {source}}`. Double-clicking it opens the Code tab with that source; its interface
   (ports/inputs/outputs) updates from `check/block`; a connection to a port that disappeared
   must turn red/error and be reported (E101 in the diagnostics panel comes from `model.check`,
   but the canvas should mark it immediately).
6. Listen for the `bgsim:open-source` event and open the requested source at the given line.
7. Changing the source of an inline block is an undoable document mutation through the store.

### 3. Tests
- vitest: the lint mapping (offsets, multi-line ranges, severity), the autocomplete sources, the
  read-only banner, the inline-source edit being undoable.
- Playwright (`tests/e2e/code.spec.ts`): open the Code tab, type a block with an error (`=` in
  `@equations`), see a squiggle whose tooltip carries E001 and the hint; fix it to `~`, see the
  squiggle disappear and the canvas node's ports update (add a port to the source and watch the
  node gain it).
- Keep every existing web test green.

### 4. Ownership
You own `web/src/code/` and may edit `web/src/editor/` where the inline-code and
double-click behaviour requires it (report every file). Do not edit `web/src/app/*.tsx`,
`web/src/inspector/`, `web/src/diagnostics/`, `web/src/plot/` or `web/src/state/documentStore.ts`
beyond adding an undoable command if one is genuinely missing (report it). Do not touch
`backend/`, `julia/`, `contracts/`, `tools/`, `plan/`, `spec/`. Do not run any `git` command.
