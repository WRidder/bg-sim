### 3. `tools/check.py --lane x`
The examples lane runs `examples/run_checks.py` if it exists (read `tools/check.py`). Add
`examples/run_checks.py`: a uv script that, for every `examples/<name>/expected.json`, starts
the real worker through the backend (`uv run bgsim` with the real worker, or the worker
directly), runs the model, reads `columns.f64`, and asserts the checks. Print one line per
check and exit non-zero on failure. This is the mechanism the M1 gate uses, so make it
general (discover examples by directory) rather than special-cased.

### 4. Playwright

model, plot the shaft speed, and assert the cursor readout at `t = 0.2 s` is `239.8 ± 0.1`.
Add an npm script or document how to run it with the real worker (`BGSIM_FAKE_WORKER` unset).
