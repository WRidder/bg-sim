## Orchestrator notes

### 1. Interfaces
W1.1 landed: the store, canvas and library. M0.5 built the bottom-dock tab host and the top
bar. You own `web/src/plot/` and `web/src/app/RunBar*`.
The backend (P1.2, may land slightly after you) provides
`POST /api/projects/{p}/runs`, `GET /api/runs/{id}`, `GET /api/runs/{id}/data?ids=&t0=&t1=&px=`
(binary `u32 n_signals`, `u32 n_points`, then Float64 columns) and `WS /ws/runs/{id}`. The
fake worker answers all of them; read `backend/src/bgsim_server/runs.py` and `worker.py` for
the exact shapes, and `contracts/schemas/run-manifest.schema.json` for the manifest. The
`/data` response is binary — parse with `DataView`/`Float64Array` over the little-endian
buffer, not JSON.

### 2. Deliverables (plan 7.5, 7.2)
- `RunBar`: run, stop, the settings controls (`t_end`, solver, tolerances) bound to the model
  document's `settings`, a progress readout (`t / t_end`), and the run status
  (`compile`/`simulate`/`done in X s`). Keyboard Ctrl+Enter runs, Esc cancels a drag.
- Signal browser: a tree by instance path with search, kind icons (state, algebraic, port
  e/f/P, discrete, input/output), units shown, double-click to add to the active plot.
  Source it from the manifest's `signals` (plan 3.5) or from `model.check`'s `signals`.
- Plot panels: 1..n stacked **uPlot** instances with time axes linked through `cursor.sync`,
  one y-axis per unit group (at most 2 per panel, then suggest a new panel), a legend with the
  values at the cursor, wheel/drag zoom, double-click reset, and a zoom change that
  re-requests `/data` with the new `t0`, `t1` and `px = canvas width × devicePixelRatio`.
  Keep an LRU cache keyed `(run, id, t0, t1, px)`.
- `px` must be `0` (raw) for a "show all" case and the decimated path otherwise.
- Empty state: a guidance message telling the user to run the model and drag a signal here.

### 3. Tests
- vitest: the binary `/data` parser against a hand-built buffer; the LRU cache key; the
  unit-group axis assignment; the legend cursor formatting.
- Playwright (`tests/e2e/plot.spec.ts`, fake worker): run the model, add 3 signals, see 3
  series rendered, zoom, and assert that `/data` was re-requested with new `t0`/`t1`
  (intercept the request with `page.route` and record the query strings).
