## Orchestrator notes

### 1. Read first
`julia/BGSim/NOTES.md` sections "J1.1 — the language front end" and (if present) the J1.2
units section. J1.1's public API is frozen: `parse_block`, `check_block`, `block_interface`,
`block_equations`, `constant_env`, the AST node types, the accessors and the `Diagnostic`
type. **Do not rename or restructure those**; extend the AST with new node types and new
scopes, and add accessors where needed. J1.2/J1.3/J1.4, J2.2/J2.3/J2.6 all consume this API.

### 2. What this WP must deliver
1. **Vec/Mat**: literals `[1.0, 2.0]` (vector) and `[1 2; 3 4]` (matrix), `Vec{N}`/`Mat{N,M}`
   sizes from literals or `@constants` (D13: overridable structural constants), indexing
   `v[i]`, `M[i, j]`, sizes checked against declarations (E005), matrix multiplication and
   `A \ b` in expressions. Static only: a size that is not resolvable from `@constants` is
   E005.
2. **`for i in 1:N`** unrolled in `@equations`/`@initial` and in discrete scopes; `N` must be a
   static constant; a non-constant bound is E005; the loop variable is checked against the
   index range of any array it indexes.
3. **`if` equations**: only around whole equations, each branch with the **same number** of
   equations (otherwise E001/E005 with a clear message naming the counts). Also `elseif`.
4. **`ifelse`** anywhere allowed by the spec table, including in defaults and sizes.
5. **The whole function whitelist** of the spec, row by row, plus the **intrinsics table** of
   plan D12 (`interp1`, `interp2`, `noise_normal(seed, k)`, `delay`) with a `stdlib_only` flag
   (users may call `interp1`/`interp2`; the rest only from `stdlib/` blocks). The whitelist
   table is the single source: every row needs an allowed test and a rejected test (`E002`) in
   the same testset, so a missing row is visible.
6. **`@initial`**: parse and check like `@equations` but with `initial` semantics; equations
   only, no `ddt`.
7. **`@discrete Ts = … [offset = …]`**: parse the header (a real literal or a constant
   expression), then the imperative body: assignments `x = e`, `x += e` (and the other
   compound forms), `if/elseif/else`, `for`, `reinit`? no (`reinit` is `@events` only),
   `previous(x)`, `hold(x)`, comparisons and boolean operators, `Int`/`Bool` locals, and
   **D18**: an assignment to an undeclared name creates a block-local temporary whose type and
   size come from the assigned value; it is not stored between ticks. In `@equations` an
   undeclared name stays E003.
8. **`@events`**: `cond => begin … end`, where `cond` is a real expression (upward zero
   crossing) or a comparison `a < b` / `a > b` (D19); the body may assign discrete variables
   and call `reinit(x, v)`. Parsing and checking only — J2.3 lowers it.
9. Type checking in discrete scopes per the spec: `Bool` only in conditions and logic, `Int`
   only in discrete code/indices/constants, no implicit Real→Int. A `Bool` continuous state is
   E004.
10. **Balance counting** must now expand Vec/Mat, exclude discrete variables, count `if`
    branches, and unroll `for` loops (plan 4.4).

### 3. Golden checks required
`SpeedMonitor` (spec), `LQGController` (plan 9.5, verbatim from the plan) and `Ball` (plan 9.2,
verbatim). Each must parse with **zero** diagnostics, produce the expected interface, and pass
its block-level balance count. Also add a test that `@initial`, `@discrete`, `@events` are no
longer rejected by the "not supported yet" E001 (J1.1 added that rejection intentionally).
