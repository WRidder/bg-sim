### 2. What `src/library/` must provide
```julia
BGSim.Library.load_source(text; ref, path) -> ParsedBlock        # parse + check, cached by source hash
BGSim.Library.stdlib_dir() -> String
BGSim.Library.load_stdlib() -> Vector{BlockDef}                  # every file under stdlib/, sorted by ref
BGSim.Library.load_project_library(dir) -> Vector{BlockDef}      # library/<Name>.jl, one @block per file
BGSim.Library.catalog(project_dir=nothing) -> NamedTuple         # plan 3.2 shape
BGSim.Library.intrinsics() -> the intrinsic table of D12       # interp1, interp2, noise_normal, delay
BGSim.Library.BlockDef
```
`BlockDef` is the IR type of plan 5.1: name, ref, source, path, the interface, the AST and
the diagnostics. Keep it immutable and JSON-serialisable (`to_dict`).
Caching: key on the source text hash (`SHA` from the stdlib is available; add `SHA` if you
need it, it is a stdlib package — use `Pkg.add("SHA")` in `--project=julia/BGSim`).
`ref` for a stdlib block is `stdlib:<group>/<Name>` where `<group>` is the directory under
`stdlib/` (e.g. `stdlib:bondgraph/C`); for a project block `project:<Name>`.

### 3. The M1 stdlib (plan section 8, M1 column) — write every one, in the language

Use the spec's parameter names and units (the catalog fixture `contracts/fixtures/catalog/valid/catalog.min.json`
lists all 36 M1 blocks with realistic parameters — read it and match it; if you disagree with
a fixture detail, follow the spec and say so in your report). Every parameter needs a
`description`; every block must pass `check_block` with **zero errors**. `DCMotor` is written

`v = R*i + L*ddt(i) + k*w_rel`, `T = k*i`, rotor inertia `J` and damping `d` between `shaft`

`Noise`, `TimeTable`, `delay`, `interp1`/`interp2` are **M2** (`J2.7b`): do not write them
