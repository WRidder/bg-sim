`worker.py` (the supervisor + fake worker), `__main__.py`, `tests/`. P1.3 added `proxy.py`,

P1.3 also provides `create_app(settings, worker_factory=...)` for tests and

### 2. Requirements (plan 3.7 and section 6 `projects.py`)
- `GET /api/projects` — list projects under `projects_root` (default `~/bgsim-projects`,
  `BGSIM_PROJECTS_ROOT`).
- `POST /api/projects` — create, either empty or from an example (`{ "name", "example"? }`),
  which copies `examples/<name>/` into the new project.
- `GET /api/projects/{p}` — open: the project file plus its models and library listing.
- `GET/PUT/DELETE /api/projects/{p}/models/{m}` — model documents; **PUT validates against
  `model.schema.json`** using the generated pydantic models in `bgsim_server/contracts.py`
  and returns 422 with the validation detail on a bad document.
- `GET/PUT/DELETE /api/projects/{p}/library/{block}` — project library sources
  (`library/<Name>.jl`).
- Safe path handling: reject `..`, absolute paths, drive letters, and any name that is not
  `[A-Za-z_][A-Za-z0-9_]*` (blocks) or a safe file name (projects/models). Return 400.
- Atomic writes: temp file in the same directory + `os.replace`, always LF newlines.
- A `ProjectStore` class that takes `projects_root` in its constructor so tests use a
  `tmp_path`, and a FastAPI dependency that builds it from config.
- Project file shape: `contracts/schemas/project.schema.json` (read it;
  `{format, language, name, models, libraryDir, scenesDir}`).
- `create-from-example` copies `examples/<name>` recursively; if the example does not exist,
  404 with a message naming the available examples.

### 3. Tests
pytest with `tmp_path` for: CRUD on projects, models and library; path traversal attempts
(`../x`, `..\\x`, `C:/x`, `/abs`, `a/b`) all rejected; atomic write leaves no partial file and
always ends with LF; a model PUT with an invalid document is rejected 422; create-from-example
copies the tree. Use the fake worker (`BGSIM_FAKE_WORKER=1`) or no worker at all — this WP
must not need Julia.
