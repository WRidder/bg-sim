## Orchestrator notes

### 1. What already exists (do not redo it)
P1.2 built `runs.py` completely: start/cancel, the manifest, `/data`, CSV, the run WebSocket
at both `/ws/runs/{id}` and `/api/ws/runs/{id}`, **live decimated tails** for subscribed signal
ids, and **run-history pruning**. Its tests (15) pass, and `decimate.py` is a pure module with
a brute-force reference test. P1.3 built `proxy.py` with `/api/check/block` (no coalescing yet).
So read `runs.py`, `proxy.py`, `tests/test_runs.py` and `tests/test_proxy.py` first, and treat
this WP as **hardening plus the one missing feature** (coalescing), not a rewrite.

### 2. What to build
1. **`/api/check/block` request coalescing** (the actual gap): the editor calls it on every
   keystroke (debounced 300 ms). When a new request arrives for the same block key
   (`ref` + a project or "stdlib" key), a still-running older request must be **abandoned**:
   cancel the worker request if the supervisor supports it, or at least stop waiting and let
   the new result win. Only the newest answer may reach the client. Add a per-client/per-ref
   in-flight registry, a bounded queue (latest wins, do not queue more than one), and a test
   with a scripted slow worker that proves the stale answer never returns and that the worker
   sees at most 2 calls for 5 rapid requests.
2. **Live tail rate limit**: assert and enforce **at most 20 messages per second** per
   subscriber (plan 3.6). If P1.2's implementation is already at or below that, add the test
   that proves it (count messages over a synthetic 2 s live run); if it is not, add the
   coalescing/timer that makes it true.
3. **Backlog on late subscribe**: a subscriber that connects mid-run must receive the data
   recorded so far for its ids (decimated) and then the tails. Test it.
4. **History pruning**: verify the plan's "last 20 runs per model, configurable" behaviour and
   its env var; add the missing test if there is none.
5. **`stream.py`**: do **not** implement the spec stream format (that is P5.1). If a shared
   tail-reading helper is needed, put it in `stream.py` and say so; otherwise leave the file for
   P5.1.
